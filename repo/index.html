VoxCordis for apt and dnf

Version 0.3.5. Updates arrive through your package manager like any other package. The repository and every package in it are signed.

Debian, Ubuntu, Mint and relatives (apt)

sudo install -d -m 0755 /etc/apt/keyrings
curl -fsSL https://voxcordisai.com/repo/voxcordis.gpg | sudo tee /etc/apt/keyrings/voxcordis.gpg >/dev/null
echo "deb [signed-by=/etc/apt/keyrings/voxcordis.gpg] https://voxcordisai.com/repo/apt stable main" | sudo tee /etc/apt/sources.list.d/voxcordis.list
sudo apt update
sudo apt install voxcordis

Fedora and relatives (dnf)

sudo curl -fsSL -o /etc/yum.repos.d/voxcordis.repo https://voxcordisai.com/repo/rpm/voxcordis.repo
sudo dnf install voxcordis

Good to know

64-bit x86 only, glibc 2.35 or newer (Ubuntu 22.04, Debian 12, Fedora 36 and later). The key's fingerprint is A73F603FB025D173D8ED3364D0D8F7338D36D04B; the key itself is voxcordis.asc.

Installed this way, VoxCordis does not update itself; it tells you when a new version is out and the command to run. Prefer a single file? The AppImage and the Windows installer are on the releases page.
