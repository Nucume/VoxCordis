Meet Voxette

This is VoxCordis, rebuilt for the web and filled with an example companion. Everything in the window works, and what you do in one part shows up in the others.

Tap one of the suggestions, or write anything you like.

It remembers what matters

Voxette writes down what's worth keeping and updates it when things change. The Memory tab shows all of it. Search, pin, fix or forget anything, and bring back what you forgot.

Tell Voxette something in the chat and it lands here.

Its personality is a file you can edit

Every companion has its own folder with its personality, the lessons it has learned and what it keeps private, as plain Markdown. Change a line and Voxette reads it before the next reply. As it gets to know you, it may rewrite its personality itself.

Go ahead and edit personality.md.

Reminders and routines

Ask in the chat and Voxette sets it up. Reminders and tasks keep running in the background, even with the window closed, if you like.

Teach it new skills

A skill tells Voxette how to do one particular thing. It uses one when it fits, or you call it up with /name. Claude skills import as they are.

It draws, on your computer

Built-in Stable Diffusion with SDXL, anime and photo models, or your own .safetensors with LoRAs. Voxette picks the model itself, or you draw by hand. An InvokeAI you run works too.

This page paints its pictures itself to show the idea. The app uses a real model on your graphics card.

Make it look like home

Light or dark, a Colorway, a background picture of your own. Try a few and the whole page follows. Or let Voxette choose for itself.

Private by default

Everything stays on your computer unless you choose a server-hosted brain, and the app tells you when you do.

No accountNothing to sign up for. It works offline.
Your graphics cardA built-in llama.cpp brain. Pick a recommended model or bring any .gguf.
Encrypted on diskChats and memories, with a key kept in your keyring.
Online only if you askWeb search and its own browser are opt-in. Your home network stays off limits.

Download

VoxCordis updates itself in one click. Every update is checked against its checksum and the VoxCordis release signature before it installs.

Windows

Windows 10 or 11, 64-bit. The installer isn't code-signed yet, so SmartScreen may warn the first time. Choose More info, then Run anyway.

VoxCordis-windows-x64-setup.exe Download for Windows

Linux AppImage

Runs on almost any distribution, x86-64. Make it executable and run it. KDE gives the nicest see-through glass.

VoxCordis-x86_64.AppImage Download the AppImage

Debian, Ubuntu, Fedora and relatives

Install from the VoxCordis package repository, and updates arrive with the rest of your system.


    

    
macOS builds from source for now. All files and older versions are on the Releases page.
